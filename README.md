## 🚀 Featured Projects

### 1. Resulyze — AI-Powered Resume Analyzer & Candidate Ranking System

An AI-powered application that helps recruiters analyze resumes and rank candidates based on their relevance to a role.

**Key features**
- Upload and process resumes in PDF and DOCX formats.
- Generate semantic similarity scores using `all-MiniLM-L6-v2` embeddings and cosine similarity.
- Combine semantic relevance with weighted keyword, experience, project, and action-word matching.
- Rank candidates and display results through an interactive dashboard.

**Tech stack:** Python · NLP · Sentence Transformers · FastAPI · HTML/CSS/JavaScript · Docker
